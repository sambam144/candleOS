# ⚔️ All-in-One GM Screen App

This is a lightweight, single-file (HTML, CSS, and JavaScript) Game Master utility designed for tabletop RPGs and is most suited Dungeons & Dragons 5th edition. It is built to be used offline and entirely in the browser, with all data saved locally.

The application was initially generated by ChatGPT and extended/refined using Google Gemini.

## ✨ Features

* **Offline-First:** Runs entirely in your browser after the first load.
* **Initiative Tracker:** Full combat manager for PCs and Monsters.
* **Dice Roller:** Supports complex formulas (e.g., `4d6kh3+2`) and logs all rolls.
* **Data Management:** Track Party Stats (HP, AC) and manage custom Notes.
* **Bestiary & Items:** Editable catalogs for Monsters and Magic Items.
* **AI Generators:** Includes tools to generate NPCs and Locations using a local server proxy (requires setup).
* **Theming:** Dark, Light, and Parchment themes available.
